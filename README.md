# Lumina Sanctuary — hymn recordings

The recordings Lumina Sanctuary downloads for its hymn accompaniment: the hymns
of the *Seventh-day Adventist Hymnal* (1985) whose every stanza is timed to its
recording, so the words on the screen follow the music the whole way through.

The application fetches these itself, in the background, once a church turns
the instrumental on in **Settings › Content › Instrumental**. There is nothing
here to download or install by hand.
